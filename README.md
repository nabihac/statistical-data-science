# 🧪 Statistical Data Science Portfolio

A curated collection of applied data science labs, statistical programming implementations, and machine learning workflows executed at The University of Texas at Austin. 

This repository demonstrates a comprehensive command of the data science lifecycle, bridging the gap between raw data engineering and predictive machine learning models.

## 🧠 Core Technical Competencies

### 📊 1. Exploratory Data Analysis & Transformation (Tidyverse)
* **Data Wrangling:** Ingesting, parsing, and restructuring messy, unstructured data into clean, tidy formats using `dplyr` and `tidyr`.
* **Visual Analytics:** Engineering advanced multivariate data visualizations with `ggplot2` to isolate underlying trends, anomalies, and data distributions.
* **Multidimensional Scaling:** Implementing unsupervised learning techniques like K-Means Clustering and Principal Component Analysis (PCA) to reduce dimensionality and uncover hidden groupings.

### 🔮 2. Predictive Modeling & Causal Inference
* **Supervised Learning:** Training, tuning, and evaluating statistical machine learning classifiers to predict continuous and discrete target outcomes.
* **Regression Diagnostics:** Building multivariate regressions, constructing continuous/categorical interaction terms, and evaluating residual plots to verify linear model assumptions.
* **Causal Inference:** Designing empirical strategies to control for confounding variables and isolate true causal economic impacts.

### 📝 3. Reproducible Research
* **Automated Reporting:** Compiling live code, data tables, and statistical visualizations natively via R Markdown into presentation-ready, interactive HTML reports.

## 📁 Repository Index & Deliverables

* 📁 **Core Labs (`Lab1.Rmd` through `Lab12.Rmd`)** — Complete programmatic scripts tracking the progression from basic data visualization to complex multi-variable interaction regressions.
